    Help & keyboard shortcuts

    Get around

    Drag
    Pan (Pan tool) — middle mouse or Space+drag always pans
    Wheel / pinch
    Zoom at the cursor
    F
    Fit the whole drawing
    Z
    Zoom to a box
    + −
    Zoom in / out
    Arrow keys
    Pan (in Edit, with a selection: nudge it)
    H
    Pan tool
    L
    Layers panel (DGN: name levels with the pen, or import a names file)
    Ctrl+F
    Find text (Enter / Shift+Enter or F3: next / previous); in Edit also replace
    J
    Trace a wire: click it to light up its net (ends at cells and pins, labels, length); Esc clears
    I
    Element info: type, level, colour, weight, text, size, DGN element and offset
    B
    Dark background / white paper
    Page Up Page Down
    PDF: previous / next page

    Measure

    D

    G
    Length along a path
    A
    Area of a shape
    S

    Enter / double-click
    Finish a length or area
    Backspace
    Remove the last point

    V

    P N W

    Edit the drawing

    E
    Edit mode: select drawing items (or click the Edit tab)
    Click / Shift+click
    Select / add or remove
    Ctrl+A
    Select everything on the visible layers
    Drag a box
    Left→right: items fully inside · right→left: anything touched
    Drag
    Move (snaps; Shift keeps it straight)
    Arrow keys
    Nudge 1 px (Shift: 10 px)
    Double-click
    Edit text in place, or show points to reshape
    Right-click a point
    Delete it · right-click or double-click a side to add one
    N P R O T
    Line, polyline (C closes), rectangle, circle, text · Esc back to Select
    Layer, Colour, Weight
    For new items; with a selection they show and change the selection
    Type a number
    While drawing a line: exact length (a circle: radius), then Enter
    Key-ins
    Type XY=x,y · DL=dx,dy · DI=distance,angle in a draw tool for exact points; with a selection they move it (or copy it), AA=angle rotates it · Esc cancels
    More ▾
    Mirror, scale, array, move / copy / rotate by a value, select same level / colour / weight / type, match attributes
    Delete
    Delete the selection
    Ctrl+C / Ctrl+V
    Copy / paste, also between drawings and tabs (click places; Ctrl+Shift+V: in place)
    Ctrl+D / Ctrl+drag
    Duplicate (click places) / drag a copy (Alt+drag on a Mac)
    Right-click
    Menu: edit, copy, duplicate, rotate, delete, paste here / in place
    Ctrl+S
    Save the drawing (in Edit) · Ctrl+Shift+S save as DXF / DGN

    Touch

    One finger
    Pan (Pan tool), draw or drag with the other tools
    Two fingers
    Pan and pinch to zoom, in every tool
    Tap / drag
    In Edit: select / move; drag on empty space for a box
    Long-press
    In Edit: menu (edit, copy, duplicate, rotate, delete, paste)
    Finish / Cancel
    The bar at the bottom ends a polyline, length, area or paste

    Files

    Ctrl+O
    Open a drawing (or drop it on the window)
    Ctrl+Shift+O
    Open a folder as a sheet set (or choose or drop several drawings): a list of sheets with their titles, Find in all sheets, sheet references (“SHEET 4”, “SEE DWG …”) become links
    Page Up / Page Down
    Previous / next sheet of the set (each keeps its view and hidden layers)
    Ctrl+P
    Print or save as PDF, to scale (1:50, 1"=20') on Letter to ANSI D or A4 to A1
    Open
    Recent drawings: one click reopens them (names only are kept; Clear list forgets them)
    Edit › Save
    Saves over the file you opened when the browser allows it (asks once, keeps a backup copy if it may); otherwise downloads a copy
    Unsaved edits
    Kept in this browser until saved: reopen the drawing after a crash or a closed tab to get them back
    View › Compare
    Another revision over this one: only here red, only there green, the rest dimmed
    Esc
    Cancel / back to Pan
